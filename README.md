# ramproject
MBA Course Enquiry  Display Details

A simple PHP and MySQL web application for displaying MBA course enquiries and loading enquiry details dynamically using AJAX/jQuery.

Features

Displays MBA course enquiry records from the MySQL database.
Shows:
Serial/Enquiry ID
First name
Last name
Click a student's name to view additional enquiry details.
Details are loaded dynamically using jQuery.
Uses MySQLi 5.7 or 8.0
Uses Bootstrap 3 for basic responsive styling.

Requirements
PHP 7.x or PHP 8.x
MySQL / MariaDB
Apache web server
XAMPP, WAMP, or a similar PHP development environment
A modern web browser
